# Policy unlearning in vector-symbolic RL

An animated slide deck for the weekly meeting of 12 November 2026: how a trained hyperdimensional RL agent can forget one skill (door-key in LavaDoorKey) while it keeps the others, by editing its weights with unbind, clean up, rebind and subtract.

**View it:** https://chirathd.github.io/policy-unlearning-slides/

Controls: → or space steps through each slide, ← goes back, N shows speaker notes, O shows all slides.

- Real-valued FHRR vectors: https://chirathd.github.io/policy-unlearning-slides/versions/v2-real-fhrr.html (git tag `v2-real-fhrr`)
